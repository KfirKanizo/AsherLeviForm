מדריך הטמעה ותיעוד טכני

הטמעת Iframe חכם ומסתגל עבור טופס ביטוח דינמי מרובה שלבים

מבוא וסקירה כללית

מסמך זה מיועד למפתחים ומנהלי אתרים ומספק את ההנחיות והקוד הנדרש להטמעת הטופס בתוך אתר מארח (Host Website) באמצעות אלמנט <iframe>.

מכיוון שהטופס הנו דינמי (גובהו משתנה במעבר בין שלבים או בעת הוספת שדות ותוכן על ידי המשתמש), הוטמע בטופס מנגנון תקשורת חכם מבוסס postMessage ו-ResizeObserver המשדר בזמן אמת את מצב הטופס לאתר המארח.

המערכת מטפלת אוטומטית בשני אתגרי חווית משתמש (UX) מרכזיים:
  • התאמת גובה דינמית (Auto-Resize): מונעת הופעה של פסי גלילה פנימיים כפולים (Scrollbars). ה-Iframe מתכווץ ומתרחב במדויק לפי גובה התוכן הנוכחי שלו.
  • גלילה חכמה למעלה (Scroll-to-Top): בעת מעבר שלב בטופס, האתר המארח מקבל פקודה ומגלול את המסך בצורה חלקה חזרה לראש הטופס, כדי למנוע מהמשתמש להישאר "תקוע" בתחתית העמוד הריק.

שלבי ההטמעה באתר המארח

כדי לבצע את ההטמעה, יש להשתיל את שני חלקי הקוד הבאים בעמוד הרלוונטי באתר המארח:

1. קוד ה-HTML (אלמנט ה-Iframe)

הדבק את קוד ה-HTML הבא במיקום המדויק שבו הטופס אמור להיות מוצג בעמוד:

HTML Embed Code 
<!-- Start of embedded form area -->
<iframe
  src="https://asherlevi.com/renewalform/" 
  id="insuranceFormIframe"
  style="width: 100%; border: none; overflow: hidden; display: block;"
  title="Insurance Form"
  loading="lazy"
></iframe>
<!-- End of embedded form area -->

2. קוד ה-JavaScript (האזנה וסנכרון)

הדבק את הסקריפט הבא לפני תגית הסגירה </body> של האתר המארח. קוד זה כולל הגנת אבטחה מובנית ומאומתת מול הדומיין הרשמי של הטופס:

Host Listener Script (JavaScript) 
<script>
  (function() {
    var iframe = document.getElementById('insuranceFormIframe');
    
    window.addEventListener('message', function(event) {
      
      if (event.origin !== 'https://asherlevi.com') return;

      if (event.data && event.data.type === 'insurance-form-resize' && iframe) {
        iframe.style.height = event.data.height + 'px';
      }

      if (event.data && event.data.type === 'insurance-form-scroll' && iframe) {
        iframe.scrollIntoView({ behavior: 'smooth', block: 'start' });
      }
      
    });
  })();
</script>

הסבר מנגנון אבטחה (CORS Security - event.origin)

בתוך קוד ה-JavaScript מוטמעת שורת הבדיקה המכריעה: if (event.origin !== 'https://asherlevi.com') return;

מה זה אומר ולמה זה פועל כך?
הקוד המאזין רץ באתר המארח (האתר של הלקוח שבו מוטמע הטופס). המשמעות היא שהאתר המארח פותח "ערוץ הקשבה" להודעות חיצוניות. ללא הגבלה, כל אתר או סקריפט זדוני שייפתח בלשונית אחרת בדפדפן יוכל לשלוח הודעות מזויפות לאתר המארח ולגרום לו לשנות מימדים, לגלול את המסך בצורה פתאומית, או במקרה הגרוע לבצע מניפולציות מתקדמות על העמוד (מתקפות מסוג Cross-Site Scripting או Clickjacking).

המאפיין event.origin הוא מנגנון אבטחה מובנה בדפדפן שלא ניתן לזיוף. הוא מייצג את מקור התוכן המדויק (הדומיין) שממנו נשלחה ההודעה בפועל. הבדיקה מוודאת באופן חד-משמעי שההודעה הגיעה אך ורק מהשרת הרשמי של הטופס המקורי שלך (https://asherlevi.com). אם מקור ההודעה שונה – הקוד עוצר מיד (return) ומתעלם ממנה לחלוטין.
